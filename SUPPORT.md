# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/dynwinrt/issues) to track bugs and feature requests.
Please search the existing issues before filing new issues to avoid duplicates. For new issues, file your bug or
feature request as a new issue using the provided templates.

For questions about using the library, please open a [Discussion](https://github.com/microsoft/dynwinrt/discussions)
or file an issue.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
